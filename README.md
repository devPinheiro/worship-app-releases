# Worship App releases

Installers for Worship App, the presentation app for worship services.

Download the latest version from [Releases](https://github.com/devPinheiro/worship-app-releases/releases/latest):

- **macOS** (Apple Silicon and Intel): the `.dmg` file
- **Windows**: the `-setup.exe` or `.msi` file

Installed apps update themselves: when a new version is out, the app offers
**Install and restart**. It never restarts on its own during a service.
