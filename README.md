<h1 align="center">Prosopon</h1>

<p align="center">
  Presentation software for worship services: lyrics, slides and media on every screen,
  run from one computer, a phone or the web.<br>
  <a href="https://github.com/devPinheiro/worship-app-releases/releases/latest"><b>Download the latest version</b></a>
</p>

*Prosopon* (πρόσωπον) is Greek for *face* or *presence*.

## Download

Open the [latest release](https://github.com/devPinheiro/worship-app-releases/releases/latest)
and pick the file for your computer:

| Computer | File |
|---|---|
| **Mac** (Apple Silicon or Intel) | `Prosopon_<version>_universal.dmg` |
| **Windows** 10 or 11 (64-bit) | `Prosopon_<version>_x64-setup.exe` (or the `.msi`) |

## Installing

### Mac
1. Open the `.dmg` and drag **Prosopon** into **Applications**.
2. Open it from Applications. If macOS says it "can't be opened because it is from an
   unidentified developer", go to **System Settings → Privacy & Security**, scroll
   down, and click **Open Anyway** next to Prosopon. You only need to do this once.
3. The first time you use the phone remote, macOS asks whether Prosopon may accept
   incoming connections. Click **Allow**, so phones on the church Wi-Fi can connect.

### Windows
1. Run the `-setup.exe` (or the `.msi`).
2. If Windows shows "Windows protected your PC", click **More info → Run anyway**.
3. When Windows Firewall asks, allow Prosopon on **private networks**, so phones on
   the church Wi-Fi can connect.

## Getting started
1. **Bring in your songs:** **Import** reads EasyWorship (6/7, 2009 and `.ewsx`
   schedules), ProPresenter 6, OpenLyrics, ChordPro, SongSelect and plain-text files.
   You review duplicates before anything is added.
2. **Build a playlist** for the service and drag songs into it.
3. **Set up the screens:** in **Screens**, set the projector to **Output** and a
   screen facing the band to **Stage**.
4. **Go live:** click a slide, or use the arrow keys or space. **Clear all**, **Logo**
   and **Black** are in the live panel.
5. **Optional extras:**
   - **Countdown:** counts down to the start of the service.
   - **Messages:** an alert for the audience, or a note for the stage only.
   - **Themes and media:** backgrounds, fonts and logos.
   - **AI Listen:** follows the singing and suggests the right song.

## Phone remote
In **Remote**, choose **Pair a phone** and scan the QR code with a phone on the same
Wi-Fi. No app is needed; it runs in the phone's browser.
- **Control:** next/previous, the playlist, songs, messages and the countdown.
- **Musician view:** the whole song in large type, plus messages from the operator.

## Cloud (optional)
Prosopon works fully offline. Signing in to the cloud (**Cloud** in the toolbar) adds:
- the same library, playlists, themes and backgrounds on all your church's computers;
- the **web portal** in any browser: the live screen, song editing, playlists, the
  team, and remote control from anywhere.

## Updates
Prosopon checks for new versions when it starts and every few hours. When one is
ready it shows **Install and restart**. It never restarts on its own, so install
updates between services, not during one.

## Privacy
Your library, playlists and media stay on your computer unless you turn on the cloud.
AI Listen recognises speech on the computer itself; audio is never sent anywhere.
